1. PRÉPARATION ET NETTOYAGE DU DOSSIER JARVIS (SUR LE PC SOURCE)
   [NOTE : À IGNORER SI VOUS AVEZ UTILISÉ LE DOSSIER E:\JARVIS]
--------------------------------------------------------------------------------

Avant de transférer le dossier JARVIS sur clé USB / disque externe ou via le
réseau vers votre portable, il est recommandé de supprimer les fichiers inutiles
(caches, anciens logs de plusieurs mégaoctets, fichiers temporaires).

A) Fichiers / Dossiers exclus :
   - Les caches Python / tests : `__pycache__`, `.pytest_cache`, `.ruff_cache`
   - Les dossiers temporaires : `node_modules`, `playwright-report`, `test-results`, `.venv`
   - Les gros logs : `jarvis.log`, `tts.log`, `tts_perf.log`, `jarvis_mcp.log`
   - Les clés temporaires régénérables : `jarvis_secret.key`, `jarvis_mcp_token.txt`

3. INSTALLATION DES DÉPENDANCES PYTHON 3.12 (ACCÉLÉRATION RTX 4060 CUDA)
--------------------------------------------------------------------------------

Sur votre portable avec Windows 11 Pro, Python 3.12 et les pilotes NVIDIA :

1. Ouvrez un terminal PowerShell (ou Windows Terminal) :
   Appuyez sur [Touche Windows + X] -> "Terminal" ou "PowerShell".

2. Placez-vous dans le dossier JARVIS :
   cd C:\JARVIS

3. Créez un environnement virtuel Python dédié (Recommandé) :
   python -m venv .venv

4. Activez l'environnement virtuel :
   .\.venv\Scripts\Activate.ps1
   (Si PowerShell bloque les scripts, tapez d'abord : Set-ExecutionPolicy RemoteSigned -Scope CurrentUser)

5. Mettez à jour l'outil pip :
   python -m pip install --upgrade pip

6. Installez PyTorch avec le support CUDA 12.4 / 12.6 pour la RTX 4060 :
   pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu124

7. Installez les bibliothèques et moteurs de JARVIS :
   pip install Flask==3.1.3 Flask-Limiter==4.1.1 flask-sock==0.7.0 Werkzeug==3.1.6 requests httpx urllib3 paramiko numpy scipy faster-whisper ctranslate2 edge-tts kokoro soundfile miniaudio rank-bm25 huggingface_hub mcp starlette uvicorn psutil nvidia-ml-py loguru waitress librosa

   * Note optionnelle : DeepFilterNet (filtre anti-bruit microphone) :
     pip install DeepFilterNet
     (Si l'installation de DeepFilterNet échoue sous Python 3.12 en raison de compilateurs Rust/C manquants, ce n'est pas bloquant : JARVIS bascule automatiquement en mode audio standard sans planter).

4. GESTION DE LA VRAM (8 GO) & CHOIX DU MODÈLE RAG EMBEDDINGS
--------------------------------------------------------------------------------

Votre RTX 4060 Laptop dispose de 8 Go de VRAM.
Windows 11 et l'écran consomment ~0.7 Go de VRAM en tâche de fond.
Il reste donc environ 7.3 Go de VRAM disponible pour l'IA.

Calcul du budget mémoire :
-------------------------
- Modèle de Chat principal (qwen2.5:8b ou qwen3:8b) : ~4.8 Go à 5.2 Go VRAM

Pour le modèle RAG (recherche vectorielle dans la mémoire), vous avez 2 choix :

Option A : Modèle officiel Qwen (Recommandé par défaut)
   Modèle : qwen3-embedding:4b  (~2.5 Go VRAM)
   Total : 5.0 Go (Chat) + 2.5 Go (RAG) = ~7.5 Go VRAM.
   --> Ça passe car Ollama gère dynamiquement la VRAM (les embeddings ne sont
       chargés que quelques millisecondes pendant la recherche vectorielle).
   Commande : ollama pull qwen3-embedding:4b

Option B : Modèle ultra-léger (Optimisation maximale pour 8 Go VRAM)
   Modèle : nomic-embed-text  (~0.27 Go VRAM seulement !)
   Total : 5.0 Go (Chat) + 0.27 Go (RAG) = ~5.27 Go VRAM.
   --> Vous conservez près de 2.5 Go de VRAM 100% libre pour Whisper (STT vocal),
       le système et le TTS local sans aucun risque de swap.
   Commande : ollama pull nomic-embed-text

--------------------------------------------------------------------------------
5. CONFIGURATION D'OLLAMA & SYNCHRONISATION DU MODÈLE ACTIF
--------------------------------------------------------------------------------

1. Vérifiez que le service Ollama est bien démarré (icône dans la barre des tâches).

2. Dans votre terminal, listez les modèles installés :
   ollama list

3. Téléchargez vos modèles selon votre choix :
   # Le modèle de Chat (si pas encore téléchargé) :
   ollama pull qwen2.5:8b

   # Le modèle de RAG (au choix) :
   ollama pull qwen3-embedding:4b
   # OU
   ollama pull nomic-embed-text

4. Ajuster le nom du modèle actif dans JARVIS :
   Ouvrez le fichier `C:\JARVIS\scripts\jarvis_model.json` avec le Bloc-notes.
   Vérifiez que le nom correspond EXACTEMENT à ce qui s'affiche dans `ollama list`.
   Exemple si votre modèle est qwen2.5:8b :
   {"model": "qwen2.5:8b"}
   
   Exemple si votre modèle est qwen3.5:9b :
   {"model": "qwen3.5:9b"}

6. VÉRIFICATION DU BON FONCTIONNEMENT (TESTS RAPIDES)
--------------------------------------------------------------------------------

Exécutez ces commandes de test dans votre terminal (avec le venv activé) :

1. Tester la détection GPU NVIDIA RTX 4060 par PyTorch / CUDA :
   python -c "import torch; print('CUDA disponible :', torch.cuda.is_available()); print('Carte graphique :', torch.cuda.get_device_name(0) if torch.cuda.is_available() else 'AUCUNE')"
   --> Doit afficher : CUDA disponible : True | Carte graphique : NVIDIA GeForce RTX 4060 Laptop GPU

2. Tester la communication avec Ollama :
   python -c "import requests; print('Ollama opérationnel :', requests.get('http://localhost:11434/api/tags').status_code == 200)"
   --> Doit afficher : Ollama opérationnel : True

7. DÉMARRAGE ET UTILISATION DE JARVIS
--------------------------------------------------------------------------------

-------------------------------------------------------------------------

2. .\.venv\Scripts\Activate.ps1

----------------------------------------------

Accès à l'interface :
--------------------
Ouvrez votre navigateur web (Edge, Chrome, Brave, Firefox) à l'adresse :
http://localhost:5000
ou
http://127.0.0.1:5000

(Optionnel) Définir un mot de passe pour l'accès réseau LAN/WiFi :
Si vous souhaitez accéder à JARVIS depuis un autre appareil du réseau local :
1. cd C:\JARVIS\scripts
2. python set_password.py
3. Entrez un nom d'utilisateur et un mot de passe.
