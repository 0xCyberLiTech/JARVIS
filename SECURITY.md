<img src="https://raw.githubusercontent.com/0xCyberLiTech/0xcyberlitech/main/assets/glow-section-cyan.svg" width="100%" alt="" />

Ce dépôt public constitue exclusivement la **vitrine d'architecture et de recherche** du système d'intelligence artificielle locale **JARVIS (Stark Mark-VII FUI)** conçu par **0xCyberLiTech**.

- **Zéro Code Exécutable en Public :** Le code source opérationnel, les connecteurs Proxmox VE, la base vectorielle Hermès, les clés cryptographiques et les scripts de l'Atelier demeurent **strictement privés et confinés hors ligne**.
- **Contrôle Mécanique Avant Publication :** Chaque publication sur ce dépôt est contrôlée automatiquement par trois gardiens déterministes (`jarvis-public-doc-guard`, `vitrine-image-content-guard` par OCR natif et `vitrine-published-head-guard`), garantissant l'absence totale d'adresse IP interne RFC1918, de chemin nominatif ou de secret dans le texte comme dans les captures d'écran.
- **Portail Officiel :** La documentation R&D complète et les démonstrations audio sont hébergées sur [**https://0xcyberlitech.com/jarvis-rd.html**](https://0xcyberlitech.com/jarvis-rd.html) et [**https://0xcyberlitech.com/blueprint-jarvis.html**](https://0xcyberlitech.com/blueprint-jarvis.html).
